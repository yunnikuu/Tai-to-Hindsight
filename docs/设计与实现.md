# Tai → Hindsight 数据迁移

用户已于 2026-10-17 确认实施。Windows 中文单窗口，Python 3.12 + CustomTkinter，PyInstaller 便携单文件。

## 数据合同
- Tai: AppModels、HoursLogModels(DataTime / Time 秒 / AppModelID)、DailyLogModels(Date / Time 秒 / AppModelID)、CategoryModels。
- Hindsight: activities 为必须表，支持当前 v43 及较旧字段集合；兼容 categories、app_groups、app_group_members、process_paths。未知必填字段拒绝写入。
- Tai 为汇总数据，不存在可恢复的精确会话或截图。每小时生成一个明确标注的重建活动；逐日汇总仅补齐小时数据缺额，补齐分布不代表实际小时。
- 按进程 + 日期 + 小时标识记录，自建迁移账本映射到导入行。重复导入跳过；源累计时长变化时更新工具自己创建的行；不合并或覆盖 Hindsight 原记录。来源同一电脑是使用前提。
- 必须选择已有 Hindsight 主数据库。只读读取 Tai，事务内备份后再写目标。备份含 WAL，SHA-256 校验，备份描述文件与 JSON 报告；恢复前再次备份目标。
- 关闭 Tai 与 Hindsight 后操作。检测常见进程；不杀进程。互斥写入锁、取消回滚、预览指纹失效检查。
- 默认不入云同步队列。只迁移本地应用使用与分类、进程路径；不迁移网站、截图、窗口标题、网络请求、云账号。

## 视觉

微软雅黑 UI 字体，数据采用 Segoe UI。左主工作区与右窄状态区；上方连线表示 Tai 到 Hindsight；真实顺序为定位、预览、迁移。去掉大数字英雄区和重复卡片，以路径选择与预览表作为主体。

    Tai [来源路径  选择]  →  Hindsight [目标路径  选择]
    日期范围 / 时区 / 分类             检查结果
    应用预览表                        当前状态
    数据精度说明                      备份与恢复
    [预览] [开始迁移] [取消]

## 实现顺序
1. 从上游源码生成可解析的 SQLite schema fixture，先写真实数据库测试并观察失败。
2. 实现 schema 检查、Tai 读取、小时与日汇总转换、只读预览、批次账本、事务写入、在线备份和恢复。
3. 实现受限路径搜索、Hindsight 自定义目录/账号识别和后台任务。
4. 完成中文界面、CLI、帮助、报告、异常提示和取消。
5. 运行真实 SQLite 测试、桌面交互验证，打包并运行 exe；保留字节级回滚验证证据。


## v1.1.0 定位与弹窗改进

定位实现为 `migrator/locator.py`：支持 Windows 安装登记、启动项、快捷方式线索、历史路径、嵌套目录、Hindsight 自定义路径及多账号识别。扫描提供取消信号、目录预算、深度和时间限制，并跳过常见备份与缓存目录。

统一弹窗位于 `migrator/dialogs.py`，包括 `LocationDialog`、`MessageDialog`；界面连接位于 `migrator/gui.py`。
